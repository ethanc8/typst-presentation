A presentation about Typst, orginally written for a math audience. The slides are organized in three parts:

1. Typst itself: the project, the language, packages, templates.

1. A comparison with LaTeX.

1. Callisto: a package for using Jupyter notebooks and executing code blocks.

## Building

To compile the presentation, run

```bash
typst c presentation.typ
```
